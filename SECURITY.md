# Security policy

This repository is a curated list of links and a small check script. It runs no
service and stores no secrets, but people install what it links to, so a bad link
is a security problem.

## Report privately

Use GitHub's private vulnerability reporting on this repository ("Security" tab,
"Report a vulnerability"), or e-mail the maintainer at the address on the GitHub
profile of @basitalisandhu. You will get an acknowledgement within seven days.
Report privately when:

- a listed project has been taken over, ships malicious code, or its repository
  or domain now points somewhere else (for example a renamed account that someone
  else re-registered);
- an entry's description hides what the project really does;
- the check script or a workflow in this repository could be abused from a pull
  request.

The entry is removed or changed first and explained afterwards.

## Report publicly

Open an issue or a pull request for everything else: a dead link, an archived or
unmaintained project, a description that is out of date. See
[contributing.md](contributing.md).

## What not to send here

Do not report an unpublished vulnerability in a listed project to this repository.
Report it to that project through its own security policy.

## Supported versions

Only the `main` branch is maintained.
