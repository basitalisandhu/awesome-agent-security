## [0.1.0] - 2026-10-18

First tagged release of the list.

### Added

- The curated list of AI agent security tools, papers and datasets, with sections for runtime controls and authorization, sandboxes, scanners for MCP servers and skills, static analysis, red teaming and evaluation, incident records, threat modelling and standards.
- Entries for scoped knowledge access, a leak scanner for static analysis and an MCP and skill scanner (#8 to #10).
- `scripts/` link and format checks with tests, a live link check on every pull request and `SECURITY.md` (#11).

### Changed

- The list stands alone, without umbrella project branding (#2).
- Harden the workflows and repository policy for the OpenSSF Scorecard (#13).
